# Tool Texture Placeholders

Simple solid-color 16x16 PNG placeholders for the Day 5 basic tools.

- `items_cragpick.png` — grayish (pickaxe / cragpick)
- `items_timberaxe.png` — brown (axe / timberaxe)
- `items_soilscoop.png` — tan (shovel / soilscoop)
- `items_shortblade.png` — light gray (sword / shortblade)

These are original solid-color placeholders (similar to node textures). Replace with better original pixel art later.

Tools reference these via `inventory_image`. If a file is missing, Luanti shows a missing-texture indicator until added.
