# Node Textures

Place 16x16 PNG textures here with these exact names:

- nodes_soil.png — brown soil/dirt texture
- nodes_turf.png — green grass/turf top texture
- nodes_cragstone.png — gray stone texture
- nodes_timber.png — brown wood grain texture
- nodes_foliage.png — green leaves texture (with some variation)
- nodes_sand.png — yellow/tan sand texture (desert)
- nodes_snow.png — white snow texture
- nodes_copral_ore.png — copper-colored ore in stone (copral)
- nodes_ferrite_ore.png — iron-colored ore in stone (ferrite)
- nodes_argentite_ore.png — silver-colored ore in stone (argentite)
- nodes_aurite_ore.png — gold-colored ore in stone (aurite)

Until these files are added, the nodes will display the missing texture (pink/black) or fallback placeholders in-game.

All textures must be original artwork.
